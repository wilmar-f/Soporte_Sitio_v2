# Referencias oficiales del formato

Coloca aquí los archivos fuente para auditar la plantilla HTML:

| Archivo | Descripción |
|---------|-------------|
| `Plantilla Diagnostico.xlsx` | Plantilla Excel original (estructura y campos) |
| `*.pdf` | PDF diligenciado de ejemplo (comparación visual) |
| [`MAPA-PLANTILLA-PDF.md`](MAPA-PLANTILLA-PDF.md) | Mapa de filas/columnas, labels y placeholders del PDF |

El PDF generado por el servidor (Puppeteer) debe coincidir visualmente con el PDF de referencia, con texto seleccionable.
